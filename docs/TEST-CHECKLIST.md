## 手动 Contact Index

- [ ] 未点击“重建联系人索引”时不扫描 Outlook、不读取邮件、不发起索引请求。
- [ ] 点击后排除当前用户、草稿、发件箱、已发送、垃圾邮件和已删除邮件。
- [ ] Exchange 发件人地址可解析为 SMTP，并缓存重复解析结果。
- [ ] 每位联系人只发送最早 1 封和最近最多 3 封代表邮件的受限正文摘录。
- [ ] 单个联系人抽取失败时使用旧记录或本地基础记录，并继续其他联系人。
- [ ] 所有 AI 抽取均失败时不覆盖旧索引。
- [ ] 保存成功后生成 `contact-index.json`，已有正式文件进入 `backup` 目录。
- [ ] Inbox 旁边及其下级的自建邮件文件夹进入 Folder Context。
- [ ] 自建文件夹内邮件的发件人被关联为对应的 Contact ID。
- [ ] Inbox、已发送、草稿、发件箱、垃圾邮件和已删除等默认文件夹不作为人工标签。
- [ ] Outlook 或文件夹部分不可访问时显示警告，不导致 Outlook 崩溃。

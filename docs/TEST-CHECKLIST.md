## 语义搜索手动验收（需真实 Outlook 与真实邮箱）

### 索引

- [ ] 在一台未下载模型的电脑上直接建立索引：应弹出“模型尚未就绪”提示，
      而不是逐封报告失败；数据库中不应出现无向量记录。
- [ ] 点击“下载模型”后，状态变为“就绪”，再建立索引成功。
- [ ] 索引过程中“停止索引”按钮可用；点击后当前邮件完成后停止，
      已完成的邮件保留且可搜索。
- [ ] 索引过程中关闭服务后，连续失败会自动停止而不是空跑整个邮箱。
- [ ] 安装 Python 3.10-3.12，运行 `setup-venv.cmd`、`download-model.cmd`。
- [ ] 运行 `start-service.cmd`，确认只监听 `127.0.0.1:8765`。
- [ ] 未点击“建立 / 更新语义索引”时不扫描 Outlook、不读取正文。
- [ ] 点击后确认弹出隐私说明，可取消。
- [ ] 索引 ≥3000 封邮件时 Outlook UI 保持可操作。
- [ ] 显示进度并可取消；取消后已索引部分已保存。
- [ ] 单封邮件读取失败时记录并跳过，不中断整体。
- [ ] 重复点击索引时，未变化的邮件被跳过。
- [ ] 移动邮件后再次同步，不重新向量化，且仍可搜索。
- [ ] 删除邮件后再次同步，不再出现在结果中。
- [ ] 设置中的“删除本地索引”后，`semantic-index\mail.db` 内容被清空。
- [ ] 索引中断（关闭 Outlook）后重新打开，数据库未损坏且可继续同步。
